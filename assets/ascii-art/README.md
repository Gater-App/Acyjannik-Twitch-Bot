# Unicode-/Braille-Art

Die `.txt`-Dateien in diesem Ordner werden als UTF-8 geladen. Beim Import bitte
nicht trimmen, normalisieren oder über einen Editor kopieren, der führende
Leerzeichen entfernt. Zeilenenden, Unicode-Zeichen und Braille-Zeichen bleiben
so erhalten, wie sie gespeichert wurden.

Die vier Originalgrafiken sind noch nicht enthalten. Bitte später exakt als
folgende Dateien ablegen:

- `original-01.txt`
- `original-02.txt`
- `original-03.txt`
- `original-04.txt`

Vor dem Einchecken kann die Zeichenanzahl mit dem Bot-Loader geprüft werden.
Für Chat-Ausgabe dürfen nur bewusst ausgewählte, kompakte Varianten verwendet
werden. Große Originale bleiben für ein späteres OBS-Overlay im Asset-Ordner.
